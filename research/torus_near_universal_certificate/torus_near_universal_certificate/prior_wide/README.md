# Type 4: certified region up to Re(tau) = 9/20

For each reduced modulus tau = x + i*y with 0 <= x <= 9/20, y>0 and x^2+y^2>=1, Type 4 has an embedded intrinsically flat realization in R^3. Run `python verify.py` with Python 3 and SymPy, assertions enabled. The five intervals are certified over all w=y^2>=1-x^2; no cutoff on w is used. The exact output is in verification.txt. The five rational lifts in sections.json are inputs discovered by mixed-integer linear programming; their correctness is checked independently with rational arithmetic only. The first construction was based on Lander's flattened square seed (arXiv:2609.10703); the inflation method follows arXiv:2611.21909.

The proof is identical in structure to the earlier strip certificate in the conversation, with new parameters H=33/(20+26*x), a=H*x, D=H-1+a, r=-D/3, q=H/D. Denominators are positive, because D=(13+7*x)/(20+26*x)>0 and H+q*r=2*H/3>0. The flattened points and faces are in verify.py. The Type 4 diagonal flip is checked against the specified Lutz face list and strict convexity. Flatness follows from the exact complex angle product identities, positivity at x=0,w=1, and continuous nondegenerate faces on the connected union of the five strips. The marked modulus is established by tree-cotree development; the rank-seven horizontal cone-angle minor is checked on every strip. The two parameter tangents of the explicit family supply two independent modulus derivatives, so the joint flatness/modulus map has rank nine. All planar coordinate functions and the identities extend smoothly near each point, including boundary points.

The horizontal angle equations and modulus equations remain smooth in 3D near a nondegenerate planar base. For fixed target modulus, choose heights from the appropriate section. The verifier checks 140 edge-face separation witnesses. Every quadruple has a noncollinear projected triple, so a sufficiently small perturbation of the height vector makes the full lift generic while preserving all strict separating witnesses. For each disjoint edge and triangle, the alternating affine determinants of their five vertices encode the unique affine dependence. Intersection would force opposite signs for V0,V1 and V2,V3 and V3,V4, and equal signs for V2,V4 (in edge-first ordering); the verifier certifies at least one strict contradiction. In general position disjoint edge-face crossings are the only possible unintended triangle intersections. The generic lift is therefore embedded. Apply the implicit function theorem with a sufficiently small positive vertical scale epsilon, correcting horizontal coordinates to keep flatness and modulus exactly fixed. Undoing the vertical scaling shows embeddedness persists since the corrected horizontal coordinates converge to the original base while the unscaled height vector is fixed. In particular this method does not assert the uncorrected lifted points are already flat.

For each interval [lo,hi], substitute x=lo+(hi-lo)*t, w=1-x^2+h, where 0<=t<=1, h>=0. The exact determinant numerator is linear in the heights. The heights have positive common denominator 1+h after clearing rational constants. The script checks the signs of these unreduced numerators and denominators separately. A polynomial has the desired strict sign if all Bernstein coefficients in t of all h coefficients have the required weak sign, and the two endpoint Bernstein coefficients of the constant-in-h coefficient have the required strict sign. This certifies strict positivity or negativity throughout the unbounded domain. The sign routine returns zero for an uncertified expression, not an assertion that it vanishes.

Limitations: the region 9/20 < x <= 1/2 remains open for Type 4. Wider candidate lifts near x=1/2 failed to produce a certificate. No new Type 7 sharp-rhombic realization is proved by this package. The proof has not been independently audited.
